# Responsive College Event Portal

## 📌 Project Description

The Responsive College Event Portal is a web-based event management platform designed for college festivals and events. It provides students with event information, schedules, registration facilities, announcements, and an event gallery in a simple and user-friendly interface.

## ✨ Features

- 🏠 Homepage
- 🎉 Event Listings
- 📝 Event Registration Form
- 📅 Event Schedules
- 📢 Announcements
- 🖼️ Event Gallery
- 📞 Contact Page
- 📱 Mobile-Friendly Design
- 💻 Responsive Layout
- ⚡ Interactive User Interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
